# 01-赖程号 · 封面模板（锁定）

**这是死任务：排版、格式、间距、字体一律不得改动。**

## 唯一允许变的
- 标题文字（两行）
- 画面区里放什么素材

## 参数（与 layout.json 一致）
- 画布 1080×1920（9:16）
- 左右边距 84px
- 速報条起点 y=150，高 144px，下方 6px 白线
- 标题起点 y=362，两行，最高 94px，自动缩字号
- 红色短杠：标题下 30px，长 160px，高 6px
- 画面区 x 84–996，y 622–1500（912×878）
- 字体 Hiragino Sans GB W6

## 出图
```bash
python 板子生成-锁定.py --line1 "一行目" --line2 "二行目" --out 封面.png
```
（variant / margin / top 都有默认值，不用传）

## 禁止
改字体 · 改字号上限 · 改边距 · 改顶部位置 · 标题三行 · 标题压画面 · 非等比拉伸

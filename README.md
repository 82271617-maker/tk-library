# TK 音乐库（账号 + 音色）

这个仓库只放**长期资产**，不放每天的生产文件。

| 表 | 内容 |
| --- | --- |
| `对标账号.csv` | 账号 / handle / 链接 / 类型 / 责任人 |
| `音克隆库.csv` | 责任人 / 音色名 / voice_id / 语言 / 样音路径 / 克隆日期 |
| `音克隆库/<责任人>/<音色名>/` | sample.mp3 + voice_id.txt + meta.json |

## 规则

1. **一个责任人一个目录**，不允许共用音色目录（克隆出来的 voice_id 属于个人账号）
2. **一个音色一个子目录**，目录名就是你在对话里叫它的名字
3. `音克隆库.csv` 是索引，技能先读它，再决定用哪个 voice_id
4. 不进仓库的东西：API key、token、成片、素材 mp4

## 怎么用（给 AI）

```
用 tk-voice 配音。责任人=赖程，音色=日本新闻男声。
```
AI 会：读 `音克隆库.csv` → 取 voice_id → 逐句合成 → 去气口 → 出 mp3 + srt。
